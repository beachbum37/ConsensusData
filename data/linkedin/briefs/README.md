# Daily briefs

One file per scouring pass, written by the daily routine before it reports.

The routine's email is a notification it does not control - a quiet morning can
be judged not worth relaying, and a run that dies early sends nothing at all.
So the brief is committed here first, and the email is the copy.

That makes the absence of a file the monitoring: no `YYYY-MM-DD.md` for a
weekday means the run did not finish, whatever did or did not arrive in an
inbox. Check the routine before assuming there was simply nothing to report.
