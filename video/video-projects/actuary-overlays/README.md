# Actuary podcast — overlay cards

Five transparent cards that composite onto the cut episode. Not a video in
itself: each composition renders independently to WebM with an alpha channel,
and video-use's `render.py` lays them over the assembled cut.

## Build

```bash
cd video/video-projects/actuary-overlays
node scripts-build.mjs          # regenerate the two lower thirds
npx hyperframes lint            # must be 0 errors
for c in lt-kimberly lt-micah title-card head2head end-card; do
  npx hyperframes render -c compositions/$c.html --format webm \
      --quality standard --output renders/$c.webm
done
```

`index.html` is an empty placeholder — the CLI requires one for the project to
be valid, but nothing is built there. Every card is a standalone composition
rendered with `-c`.

The two lower thirds are generated by `scripts-build.mjs` from one template, so
the motion stays identical between speakers. Edit the script, not the generated
files.

## The cards

| Card | Length | Where |
|---|---|---|
| `lt-kimberly` | 4.0s | Kimberly's opening greeting |
| `lt-micah` | 4.5s | Micah's first substantive answer |
| `title-card` | 5.0s | after the "true cost isn't known" line, so the hook lands before the branding |
| `head2head` | 6.0s | opening of the head2head segment |
| `end-card` | 4.8s | over the sign-off, holds to the last frame |

## Two things that will bite you

**Never give `body` a background colour.** These render with alpha; a background
makes the card an opaque rectangle covering the footage.

**Initial states use `gsap.set`, not `tl.set(..., 0)`.** A zero-duration set
inside a paused timeline doesn't apply while the playhead sits exactly at 0, so
frame 0 flashes the finished card before it animates in. `hyperframes lint`
catches this as `gsap_timeline_set_initial_hide` — it is a warning, but for an
overlay it is a visible defect.

## Placing them on the cut

Output positions come from `video/tools/map_time.py`, which maps a source
timestamp through the cut EDL to where it lands in the render:

```bash
python3 ../../tools/map_time.py ../../footage/edit/edl-v2.json \
    A-true-intro 22.2 --actual-duration 709.514
```

Pass `--actual-duration` — renders run slightly longer than the EDL predicts
because every segment is padded to a whole frame, and over 124 segments that
accumulated to about 2 seconds here. The tool exits rather than guessing if the
timestamp landed in material the cut removed.
